Run Splice on Windows 11

The sample workspace runs in your browser. For live SSH, tmux and Kiro CLI, launch the local bridge from the source repository.

Open the source repository

  1. Install Node.js 22.12 or newer, Git, Windows OpenSSH, and Rust through rustup. Install and sign in to Kiro CLI with the V3 harness.
  2. Configure an SSH alias for an authorized Linux host with tmux. Verify the host key in OpenSSH.
  3. Copy splice.example.json to splice.local.json and set the alias, Git checkout path, and source files the agent can read.
  4. From the repository root, run the commands below and open the single-use link printed by the bridge.
npm ci
rustup target add wasm32-unknown-unknown
npm run build:wasm
npm run build
npm start

The repository README includes a disposable Linux fixture and an end-to-end retry incident walkthrough.
