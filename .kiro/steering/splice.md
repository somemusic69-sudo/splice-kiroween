# Splice

Splice connects a human-operated SSH/tmux session to browser-side log triage and Kiro-assisted patch review. Keep the local bridge on IPv4 loopback. Use the disposable retry-worker checkout for all incident exercises.

The operator decides what excerpt to share and which reviewed patch to apply. Keep raw logs in the browser worker. The incident agent reads supplied evidence as data and proposes a text diff. Keep tests and deployment in the operator's terminal.

Use the existing Node bridge, Rust log crate, and CSS terminal layout when working on the feature. Use the exact fixture regression contract in the retry incident spec.
